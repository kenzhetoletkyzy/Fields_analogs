# Пластовые аналоги РК

Статическое веб-приложение (один файл `index.html`, без сервера и сборки).
Встроенные данные — `Choice_RF.xlsx`; новый .xlsx той же структуры загружается прямо в интерфейсе.

## Публикация на Vercel

**Вариант 1 — через сайт (без установки программ)**
1. Создайте пустой репозиторий на github.com и загрузите в него файлы этой папки (Add file → Upload files).
2. Откройте https://vercel.com/new, выберите репозиторий → Import.
3. Framework Preset: **Other**, Build Command и Output Directory оставьте пустыми → Deploy.
4. Через ~30 секунд Vercel выдаст ссылку вида `https://<имя-проекта>.vercel.app`.

**Вариант 2 — через командную строку**
```
npm i -g vercel
cd kmge-analogs
vercel --prod
```
При первом запуске Vercel попросит войти в аккаунт и задать имя проекта.

## Обновление
Замените `index.html` в репозитории — Vercel переразвернёт сайт автоматически.
Данные, загруженные пользователем через интерфейс, хранятся только в его браузере.

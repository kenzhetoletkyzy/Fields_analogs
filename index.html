Распознаваемые колонки
    Средние — арифметические; проницаемость по умолчанию в расчёте берётся по медиане. Строковые значения вида «4330/4344.4» или «0.54-0.55» усредняются; числа вне физически допустимого диапазона параметра отбрасываются. Дебит — оценка установившегося плоскорадиального притока к вертикальной скважине (Дюпюи), без учёта неоднородности, интерференции и нелинейной фильтрации. Данные с меткой «лит.» — ориентировочные значения по открытым публикациям, требуют уточнения.
